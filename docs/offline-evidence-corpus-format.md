# Offline Evidence Corpus Format

The offline retrieval baseline accepts UTF-8 JSONL files. Each line is one
document and is treated as local data only; the loader never fetches its URL.

## Required fields

```json
{
  "document_id": "doc-001",
  "title": "A fictional document title",
  "text": "Fictional local evidence text.",
  "source_category": "official_government",
  "language": "en",
  "content_hash": "sha256:..."
}
```

Required fields are `document_id`, `title`, `text`, `source_category`,
`language`, and `content_hash`. Optional fields are `url`, `publisher`,
`published_at`, `retrieved_at`, and `license`.

The loader rejects missing IDs, empty text, unsupported languages, invalid
source categories, duplicate IDs, and duplicate content hashes. It recomputes
the SHA-256 hash of `text`; a supplied hash must match it. Source metadata may
be required to pass a separate approval policy before citation.

The current allowed language set is `hi`, `en`, `hinglish`, and `romanized_hi`.
The source categories are the India-first categories defined by the source
policy. The fixture at `backend/tests/fixtures/evidence_corpus.jsonl` is
fictional test data and must not be used for research metrics.

## Storage and provenance

The document URL is metadata, not a retrieval instruction. `retrieved_at`
describes how the local document was obtained and is not generated by this
baseline. Full-page storage and live web access remain disabled.
